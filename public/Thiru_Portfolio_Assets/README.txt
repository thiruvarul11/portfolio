THIRUVARUL PORTFOLIO ASSETS

This package contains the real resume PDF and uploaded profile photo for the portfolio.

Files:
- public/resume.pdf
- public/images/thiruvarul-profile.jpg

How to use:
1. Extract this ZIP into the root of your existing portfolio project.
2. If asked whether to overwrite, check the existing files first and preserve anything you still need.
3. For a Vite/React app, reference the resume at /resume.pdf (not /public/resume.pdf).
4. Reference the photo at /images/thiruvarul-profile.jpg (not /public/images/thiruvarul-profile.jpg).
5. The website's Resume button should link to /resume.pdf with download="Thiruvarul_K_Resume.pdf".

The PDF is the original uploaded resume. The profile photo was copied from the image supplied in chat.
